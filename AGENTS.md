# Repository Instructions

Act as a careful engineering partner. Inspect the relevant code and evidence,
use technical judgment, and verify changes before presenting them.

For this repository, work and commit directly on `main` and push completed,
authorized task changes to `origin/main`. Create a feature branch or pull request
only when the user explicitly requests one. This is the owner's instruction
from 8 October 2026.

Preserve source provenance and state the numerical scope supported by actual
experiments. Do not turn an unverified physical or performance claim into a
publication result.
